# Ruang Bajet

Dashboard kewangan peribadi statik, responsif dan editable. Semua perubahan disimpan dalam `localStorage` browser — tiada server atau database diperlukan.

## Terbitkan di GitHub Pages

1. Cipta repository GitHub baru, contohnya `ruang-bajet`.
2. Upload `index.html`, `styles.css`, `app.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, kemudian **Save**.
5. Selepas GitHub selesai deploy, laman boleh diakses di `https://USERNAME.github.io/ruang-bajet/`.
